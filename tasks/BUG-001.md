# BUG-001 정산 금액 분배 시 나머지 금액 유실

## 상태

OPEN

## 우선순위

High

## 대상 모듈

`sample-project/src/expense/splitter.py`

## 문제 상황

정산 금액을 인원수로 나눌 때, 나누어떨어지지 않는 금액에서 나머지가 유실된다.

10,000원을 3명에게 분배하면 현재 각 사람에게 3,333원이 배정되어 총 9,999원만 분배된다.
따라서 원래 금액과 실제 분배된 금액의 합계가 일치하지 않는다.

## 재현 절차

```python
from expense.splitter import split_amount

result = split_amount(10000, 3)
print(result)       # [3333, 3333, 3333]
print(sum(result))  # 9999
```

## 현재 동작

- `split_amount(10000, 3)` → `[3333, 3333, 3333]`
- 분배 금액의 합계: 9,999원
- 입력 금액과의 차이: 1원 부족

## 기대 동작

- 분배 금액의 총합은 항상 입력 금액과 같아야 한다.
- 사람별 금액 차이는 최대 1원이어야 한다.
- 나머지 금액은 일정한 기준으로 배분되어야 한다.
- 기존 입력값 검증 동작은 유지되어야 한다.
  - `people <= 0` 이면 `ValueError`
  - `amount < 0` 이면 `ValueError`
- `format_split` 의 동작에는 영향을 주지 않아야 한다.

## 영향 범위

- 나누어떨어지지 않는 모든 정산 금액
- 인원수가 많을수록 유실 금액이 커진다 (최대 `people - 1` 원)
